На staging опубликован `d2fda78`, CI и четыре проверки реального интерфейса для чтения успешны. Новый каталог карточками, партии и сроки, защищённый предпросмотр, меню, короткая помощь, категории AI и раздельные статусы модели/Java/фона сохранены. Из товара можно подготовить безопасное социальное предложение, организации управляются внутри ARIA Impact. Передача проверяет конкретные партии и не использует неподтверждённый остаток. [Коммиты, снимки и точка продолжения](../ux/CHECKPOINT_RU.md).

Опубликованы управление изображением с удалением/защитой версии, работа складского сотрудника и подтверждённая сохранность учебных данных. Ближайший сохраняемый этап — понятный экран рынка и исключение старых случайных ориентиров; его публикация проверяется отдельно.

Полный учебный супермаркет проверен отдельно локально: 64 синтетических товара с оригинальными иллюстрациями + 16 прежних справочных, поставщики/партии/закупки, 28 продаж через POS, возврат, реальные Java-рекомендации и социальные черновики. Прежние записи не удалялись; после дополнительных сценариев в локальной базе 84 товарные записи, 153 партии, 31 заказ. Цены/сроки/продажи/выдача учебные. Это не рыночные наблюдения, не продажи пользователя и не ответы нейросети.

Сквозные действия в Edge: количество в каталоге/карточке/корзине, оформление и отмена заказа со складом, доступ/проверка учебного получателя, резерв/акт/учебная выдача 40→37, приёмка/закрытие партии сотрудником и немедленный отзыв его доступа. Данные сохранились после перезапуска. В новой среде OpenRouter выключен; Java помечен честно.

Новая онлайн-компания пока не активируется автоматически. Подача заявки/восстановление по коду работают. Базы/роли A/B подготовлены с разрешения владельца, но их Render-процессы не настроены; аккаунт владельца B не создан. Отдельный пустой проект Neon Free для супермаркета создан без копирования данных, приложение ещё не опубликовано. Способ передачи секретов через stdout был отклонён; его не повторяли. Требуется защищённое подключение/импорт без вывода значений. [Подробности P13](SELF_SERVICE_RU.md).

Оставшиеся ограничения: одно назначенное изображение товара; автоматический поиск рынка ещё не подключён; публичное API мониторинга Kaspi не подтверждено; новый staging без внешнего AI/коммерческого WooCommerce. Учебный E2E не объявляется проверкой магазина владельца. Главная ветка, production, реальные базы и согласия существующих компаний не менялись. Платные ресурсы не создавались.

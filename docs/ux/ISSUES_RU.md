# Единый реестр UX ARIA

Начальная проверка: настоящий Edge, staging `2b231a0`, 15.11.2026. Использован разрешённый владелец отдельной тестовой компании. Исходные данные и согласия не изменялись. Наблюдения до исправлений сохранены в закрытой рабочей папке `data/ux-audit`; публичные доказательства добавляются после проверки.

- **UX-01 · P1 · исправлено и проверено онлайн (`abdc05c`).** Меню компании не закрывается при выборе пункта, смене раздела, клике снаружи и Esc вне меню. Тот же тип меню реализован отдельно в товарах/складе/магазинах. Решение: единый компонент закрытия, фокуса, клавиатуры и `aria-expanded`, без сворачивания обычных пояснений.
- **UX-02 · P1 · исправлено и проверено онлайн (`abdc05c`).** «Подключённых магазинов: 1» в товарах при нуле проверенных подключений: незавершённая настройка считается подключением. Нужны согласованные состояния и верное следующее действие.
- **UX-03 · P1 · исправлено и проверено онлайн.** Партии не имеют очевидного пути «Склад → Партии и сроки → товар»; по умолчанию сверху закрытые партии, нет выбора товара. Нужны выбор товара, реальные фото/placeholder, понятные действия и видимые риски срока.
- **UX-04 · P1 · исправлено и проверено онлайн.** Мастер AI требует вручную вводить категории через запятую. Аналогичные текстовые поля есть в ценах и подключённых магазинах. Нужен общий выбор фактических категорий без расширения разрешений при пустом выборе.
- **UX-05 · P1 · исправлено и проверено онлайн.** В AI-центре данные собственного каталога ведут в магазины, ссылка неподключённой модели ведёт на тот же раздел без действия, незавершённый магазин предлагает «Возобновить». Причины остановки управляющего и модели нужно показывать раздельно.
- **UX-06 · P1 · исправлено, браузерная проверка успешна; готовится публикация.** «Помощь» — длинная техническая инструкция со старыми названиями разделов. Нет интерактивного знакомства и постоянного короткого пути к нему.
- **UX-07 · P0 · исправлено и проверено онлайн (`abdc05c`).** Подтверждены 401 трёх запросов без сеанса. Добавлены авторизованные чтения и закрытый предпросмотр владельца, понятная страница для посторонних и двусторонняя навигация. Ошибка больше не оставляет индикатор загрузки. В Edge с новым интерфейсом и настоящим API staging открылись каталог и карточка, затем кабинет. Это ещё не проверка опубликованного кода.
- **UX-08 · P2 · исправлено, RU/EN проверены; готовится публикация.** Английские технические заголовки в русской главной и AI («INTELLIGENT RETAIL OPERATING SYSTEM», «PRODUCT FLOW», «CONNECTED COMMERCE»). Перевести системную копию, не переводя данные магазина.
- **UX-09 · снято после проверки.** Подпись поиска цен правильно связана с полем. Причиной недоступности при первом поиске было перекрывающее меню (UX-01), отдельного дефекта подписи не подтверждено.
- **REG-01 · P0 · внешний блокер, не часть UX-исправления.** Самостоятельная регистрация новых компаний остаётся выключенной после остановки безопасностью передачи Render-секретов. Две пустые базы готовы; новое задание UX не является разрешением обходить отказ.

Проверены чтением: вход, главная, товары, заказы, склад/партия, закупки, аналитика, магазины, AI/мастер, Impact, настройки и помощь. Далее — формы, сотрудники, витрина, роли, 390 px, RU/EN и обе темы. Контрактные тесты не объявляются опубликованным E2E.

- **UX-10 · P1 · исправлено и проверено онлайн (`abdc05c`).** Смена пользователя внутри одной компании не закрывала прежнюю вкладку: сравнивалась лишь компания. Теперь до/после запросов, при фокусе, восстановлении вкладки и событии хранилища проверяется весь сеанс. Старый экран очищается; новый вход другой вкладки не удаляется. Серверная авторизация остаётся обязательной.

- **UX-11 · P1 · исправлено, готовится публикация.** Ссылка «Открыть склад» из партии не закрывала карточку, если склад уже открыт. Навигация ссылками из общего диалога теперь использует ту же проверку несохранённых данных, даже без изменения адреса.
- **UX-12 · P1 · исправлено, готовится публикация.** Поздний ответ истории партии мог заменить другую уже открытую карточку. Результат привязан к своему окну и сеансу.

- **UX-13 · P1 · исправлено и проверено компонентным тестом.** Загруженные частные фотографии на витрине запрашивались обычным изображением без сеанса. Теперь защищённый файл читается только с собственным доступом, перед отображением проверяются тип, размер и неизменность сеанса. Публичные иллюстрации сохраняют обычную загрузку.

- **UX-14 · P1 · учебный сценарий проверен локально, отдельная публикация ожидается.** Демо с единичным товаром нельзя оценить: создан защищённый повторяемый супермаркет из 80 основных товаров с 64 оригинальными иллюстрациями, партиями/продажами/возвратом. Существующая компания не засевалась.
- **UX-15 · P1 · исправлено, PostgreSQL/Edge/CI успешны, b84f28d LIVE.** Социальная передача использовала общий пригодный остаток, включавший UNKNOWN. Теперь только подтверждённые проверенные партии с условиями хранения; повторная проверка при публикации, резерве и выдаче. Непроверенные/просроченные/отклонённые партии не расходуются социальной выдачей.
- **UX-16 · P2 · исправлено и проверено локально.** Владелец мог заменить фото, но не убрать. Единая форма просмотра/замены/удаления, подтверждение прав и удаления, проверка версии перед очисткой. Товар и партии сохраняются; история остаётся. Три PostgreSQL-теста и настоящий EN/dark/390 px успешны.
- **UX-17 · P2 · исправлено, b84f28d LIVE.** Создание и проверка получателя были спрятаны на старой административной странице. Существующие операции теперь доступны из организаций ARIA Impact; категории выбираются из каталога. Доступ не означает проверку, подходящий получатель не выдумывается.

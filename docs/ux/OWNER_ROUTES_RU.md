# ARIA: короткие маршруты владельца

Все маршруты начинаются с [единого staging](https://aria-v4-staging-2ber.onrender.com/start.html). У каждого кабинета свои данные. Ниже перечислены существующие функции; внешние подключения и автоматизация требуют отдельной настройки.

1. **Вход.** «Войти» → email и пароль ARIA → кабинет. Новая заявка по-прежнему не создаёт готовую компанию: активация изолированных процессов ещё не включена.
2. **Первое знакомство.** «Помощь» → «Знакомство за 6 шагов». Каждый шаг открывает настоящий раздел; можно пропустить и вернуться позже.
3. **Свои товары без внешнего сайта.** «Товары» → «Добавить товар» → название → ручное заполнение → категория и цена → сохранить. Артикул создаёт ARIA. Складской остаток добавляется отдельно по партии.
4. **Фотография.** Меню «⋯» товара → «Изображение». JPEG/PNG, до 5 МБ и 4096 × 4096, с подтверждением прав. Можно заменить файл или убрать текущее изображение с подтверждением. Товар и остаток сохраняются. Пока поддерживается одно назначенное изображение товара.
5. **Карточка и поиск.** «Товары» → поиск по названию/артикулу/категории → «Открыть». Есть карточки/таблица, сортировка, фильтры и страницы. Источник характеристик отделён от полей владельца; учебная иллюстрация не названа фотографией SKU.
6. **Приёмка.** Меню товара → «Принять партию». Укажите фактические количество, номер, закупочную цену и срок с упаковки/документов; неподтверждённые значения не заполняются предположениями.
7. **Сроки и хранение.** «Склад» → «Партии и сроки» → выбрать товар. По умолчанию видны партии с остатком, включая просроченные. «⋯» партии открывает проверку хранения; «Открыть» — её путь и движения.
8. **Цены.** «Цены» → рекомендация → детали. Смотрите источник, действующую цену, оценку риска и ограничения. Ручное применение и автоматизация используют серверную проверку; сохранённое решение ещё не означает изменение цены.
9. **ARIA AI.** «ARIA AI» → «Автоматизация» → «Настроить ARIA». Согласия и границы выбираются отдельно. OpenRouter, автоматический Java-расчёт и фоновая служба имеют разные состояния. На текущем staging внешняя модель не настроена и фоновое управление приостановлено; локальной нейросети нет.
10. **Подготовка помощи.** «Товары» → «⋯» → «Помочь нуждающимся». Видны пригодные проверенные партии и существующие подходящие условия получателя. «Подготовить предложение» рассчитывает риск и создаёт черновик без резерва. Если получателя нет, это указано прямо.
11. **Организация и выдача.** «ARIA Impact» → «Организации» → создать доступ. Партнёр входит на этом же сайте и подаёт сведения; владелец проверяет заявку и выбирает принимаемые категории. Резерв требует явных подтверждений; выдача — времени/ответственного, документа и подтверждённого получения. Непроверенные, просроченные и отклонённые партии не передаются.
12. **Внешний магазин.** «Мои магазины» → подключение → проверка адреса → разрешённый доступ → импорт. WooCommerce необязателен для собственного каталога ARIA. Адрес API продавца не считается источником цен конкурентов; закрытая программа без разрешённого обмена не подключается автоматически.
13. **Сотрудник.** «Настройки» → «Сотрудники» → «Пригласить сотрудника». Ссылку передаёт владелец, письмо не отправляется автоматически. Складской сотрудник видит склад, не получает AI/ключи/заказы/управление людьми. «Закрыть доступ» завершает его сеансы.
14. **Покупка и история.** В публичной учебной витрине: найти товар → «В корзину» → количество → корзина → адрес → заказ → профиль. Владелец видит заказ в «Заказы»; отмена нового заказа возвращает выделенные партии. Частный B2B-предпросмотр не выдаётся за публичный магазин.

## Где проверен полный пример

Отдельный учебный супермаркет на этом ПК: [каталог](http://127.0.0.1:8087/index.html), [кабинет](http://127.0.0.1:8087/control.html#products). Это локальный просмотр, компьютер должен работать. Цены, остатки, поставщики, продажи и передачи учебные. 64 оригинальные иллюстрации + прежние 16 справочных товаров; другие прежние записи проверки не удалялись. Для справочных фактов источники указаны в карточках.

Онлайн-кабинет staging не заполнялся искусственным каталогом. Отдельный онлайн-супермаркет ещё не опубликован: требуется безопасное подключение его настроек Neon к Render, без вывода секретов. Новая компания B остаётся без созданного за владельца аккаунта. Приложение не обещает мгновенную активацию до готовности окружений.

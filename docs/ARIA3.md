# ARIA 3.0 — проверяемые итерации

## Итерация 1 — Dashboard и навигация

Открыть локально: <http://127.0.0.1:8084/control.html#workspace>. Это изолированный preview, доступный на этом компьютере. Вход — `data/preview/access.txt`; пароль не публикуется в Git. Запуск: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-preview.ps1`.

- Новая нейтральная дизайн-система для светлой/тёмной темы, 11 основных разделов, связанные инструменты во вкладках, отдельная страница настроек. Все 23 прежних раздела сохранены.
- Главная: компания, отгрузки, товары, пригодный остаток, подключения, задачи, история и фактические действия ARIA сегодня. Учебная компания обозначена явно.
- График — суммы собственных SHIPPED/DELIVERED заказов по дате отгрузки за 14 дней, включая внутренний POS без двойного счёта. Внешние заказы WooCommerce не примешиваются. При отсутствии продаж — пустое состояние.
- `GET /api/admin/control/workspace/overview`: ADMIN, та же изоляция процесса/базы; календарь Asia/Qyzylorda. Суммы — десятичные строки. Товаров проверено — уникальные товары с сохранённым анализом или завершённым исполнением; AI/ENGINE разделены. Автоматические цены — журнал применения автопилота; закупочные/социальные черновики — с происхождением менеджера. Ручные социальные предложения и будущие события исключены.
- Статус AI показывает отсутствие настройки/согласия/успешного ответа отдельно от автоматических расчётов. Этот этап не включает автоматизацию и не меняет согласия.

Проверки: `WorkspaceOverviewIntegrationTest` (2 сценария, суммы/границы/источники/401/403); `scripts/workspace-e2e.cjs` (23 раздела при 390/1440, обе темы, реальные счётчики, явно смоделированная ошибка API и восстановление, reduced motion, переходы); `scripts/stores-e2e.cjs` (существующие подключения/очередь/заказы/подписанные локальные уведомления). Все пройдены. Скриншоты до/после — `target/e2e/aria3`, отчёт — `workspace-report.json`.

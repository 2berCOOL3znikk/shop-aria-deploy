# ARIA — три шага

1. Откройте [ARIA staging](https://aria-v4-staging-2ber.onrender.com/start.html). Для новой компании выберите **«Подать заявку»**; для существующего кабинета — **«Войти»**.
2. Укажите компанию, имя и email, подтвердите два согласия и сохраните код заявки. Он позволяет открыть статус на том же сайте с любого устройства. Код заявки не является паролем входа.
3. Проверяйте статус по коду. В уже активированный кабинет входите по email и паролю ARIA. **Новая заявка пока не создаёт кабинет: облачная подготовка и активация ещё не подключены.** Сайт не выдаст вам чужое окружение вместо собственного.

Для просмотра существующего staging используйте ранее указанный email владельца и отдельный пароль из `backend/data/staging/access.txt` на вашем ПК. **ARIA-Staging-preview.cmd** открывает онлайн-версию с обычным входом. Пароль не попадает в URL или Git. Компьютер для работы онлайн-сайта держать включённым не нужно; Render Free может запускаться после простоя с задержкой.

Проверка заявок владельцем текущего staging: **Настройки → Заявки компаний**. Принятие на проверку не создаёт аккаунт, письмо или кабинет. [Что работает и где остаётся ограничение](../aria4/COMPANY_INTAKE_RU.md).

После настоящей активации подключение WooCommerce и настройка AI выполняются внутри своего кабинета. В этой новой среде коммерческий магазин и внешний AI не настроены; ключи и согласия других компаний не переносились.

# OpenRouter в ARIA

ARIA Intelligence объясняет агрегированные показатели магазина по-русски. Модель не получает инструменты изменения цен, остатков или заказов. Решения и действия подтверждает сотрудник.

## Локальная настройка

В папке `backend` создайте `.env.openrouter.local`:

```dotenv
ARIA_OPENROUTER_API_KEY=your-new-key
ARIA_OPENROUTER_MODEL=openrouter/free
```

Spring загружает этот файл при запуске из `backend`. Он исключён из Git. Не кладите ключ в HTML, JavaScript, README или коммит. Если ключ был опубликован в переписке или другом доступном месте, отзовите его в OpenRouter и создайте новый, затем замените значение в этом файле.

После перезапуска приложения войдите администратором → ARIA Control → ARIA Intelligence → запросите сводку. Без ключа, при ограничении бесплатных запросов или сбое провайдера отображаются исходные расчётные факты с пояснением причины. Ответ AI показывается как текст, не исполняется как HTML.

## Бесплатный режим

По умолчанию используется `openrouter/free`, выбирающий доступную бесплатную модель. Можно указать конкретную модель с окончанием `:free`, если она доступна в текущем каталоге OpenRouter. Доступность и качество моделей меняются; для постоянного поведения лучше выбрать проверенную конкретную модель.

При `aria.intelligence.free-only=true` (значение по умолчанию и в профиле `free`) приложение блокирует платное имя модели до отправки запроса. Запрос содержит нулевые `provider.max_price` для prompt, completion, request и image. Платного массива запасных моделей нет. Ошибка бесплатного провайдера возвращает расчётную сводку вместо платного запроса.

Внутренние рассуждения отключены для короткой сводки, лимит ответа — 700 токенов, время ожидания — 25 секунд. Некоторые модели могут игнорировать часть параметров или не вернуть полезный текст; в этом случае доступен режим правил. Ошибки авторизации и ограничения запросов отображаются отдельно, без вывода ключа или ответа провайдера с техническими данными.

Официальные источники: [Free Models Router](https://openrouter.ai/docs/guides/routing/routers/free-router), [лимиты](https://openrouter.ai/docs/api/reference/limits), [ограничение цены](https://openrouter.ai/docs/guides/routing/provider-selection#max-price).

## Онлайн-размещение

Для Render задайте `ARIA_OPENROUTER_API_KEY` и `ARIA_OPENROUTER_MODEL` как серверные переменные, не загружая локальный файл в репозиторий. Профиль `free` разрешает только бесплатные модели. Локальное подключение ключа само по себе не означает, что ключ или новая версия уже опубликованы на Render.


## Smart Pricing

Карточка решения в `/control.html#smart` запрашивает строгое JSON-объяснение отдельной кнопкой. Владелец разрешил передачу указанного в [документации Smart Pricing](SMART_PRICING.md) состава данных товара. Числовой сценарий считает Java, LLM не меняет цену. Лимит ответа здесь 1100 токенов, запросов — один в минуту на экземпляр сервера, ожидания — 25 секунд. Используются json_schema и require_parameters; недоступная бесплатная модель или неподходящий ответ дают честный ENGINE fallback. Успешное объяснение сохраняется в решении.


Активный AI Decision Service выбирает только сценарий Java и допустимую стратегию. Для ручного/фонового анализа действуют отдельные согласия и общий дневной лимит в БД. Публичный помощник имеет отдельные разрешения владельца/покупателя и передаёт только публичные поля; ответ модели содержит лишь ID, цены проверяет сервер. Все поля, API и проверки описаны в [SMART_PRICING.md](SMART_PRICING.md). Наличие ключа само по себе не даёт согласия на отправку данных.

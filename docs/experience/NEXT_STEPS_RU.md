# Продолжение с этого места

Ветка: `codex/production-foundation`. Не начинать заново. Сначала проверить HEAD, `git status`, `docs/experience/README.md` и фактический preview.

Завершены три выбранных владельцем приоритета: компактный Smart Pricing, процесс Social/Impact, новый раздел магазинов с мастером и безопасным архивом. Сохранены настоящий AI-ответ на активном товаре и доказательства. Предыдущие витрина, корзина, AI Product Draft, POS, склад и B2B-модули не переписывались.

Проверки: 208 Java/PostgreSQL; два изолированных процесса/базы компаний; цены с применением/откатом; социальная выдача/акт/CSV; магазины/подписи/архив/восстановление; 23 раздела; локальное восстановление резервной копии. Не повторять их целиком, пока новая правка не затрагивает соответствующее поведение.

**Ближайший незавершённый этап — полная RU/EN-локализация административного интерфейса.** Начать с общих меню, форм/ошибок/окон и трёх переработанных модулей, затем пройти все 23 маршрута. В `control.html` сейчас нет старого `i18n.js`: не подключать без разбора его автоматический перевод всех текстовых узлов. Использовать централизованные ключи; данные продавца, названия/описания и сохранённые решения отделять от системной копии и не переводить произвольно. Полный публичный социальный сценарий уже использует ключи `social-copy.js`; его не переделывать заново.

Далее: административный помощник через существующие безопасные Java-сервисы; категорийные характеристики; установленный WooCommerce E2E, сопоставление его данных для AI и отдельно разрешённая запись цен. Внешние карточки сейчас не передаются управляющему. Тесты с подменённым HTTP и локальные подписанные уведомления не являются установленным WooCommerce. На машине не найдены готовые Docker/PHP/MySQL-инструменты и нет ключей реального WooCommerce; не изображать подключение завершённым.

Работать законченными итерациями: реализация → подходящие тесты → браузер → исправление → commit в эту ветку. Использовать `scripts/test-postgres.ps1` для чистого PostgreSQL-прогона. Прогон `stores-e2e.cjs` создаёт явно тестовое подключение и сохраняет его в архиве; пустое удаляется только после подтверждения/проверок. Скрипт разметки старых QA-подключений запускается только в loopback-preview и только с `--apply-known-fixtures`.

Сохранить `.env.openrouter.local`, `.env.integrations.local`, `data/preview/config.json`, существующие согласия и лимиты. Новые AI-запросы — только при имеющемся согласии и через бесплатные разрешённые модели. Не сбрасывать бюджет ради теста. Статус доступности провайдера относится к текущему процессу; после перезапуска сохранённые AI-решения остаются в БД.

Никаких main, production Render/БД, платных ресурсов или отправки ключей в Git без отдельного разрешения. Университетский отчёт — дополнительный сохранённый снимок, а не замена разработки.

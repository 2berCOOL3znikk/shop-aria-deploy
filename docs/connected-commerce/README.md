# Подключённый WooCommerce: границы проверки

Ветка `codex/production-foundation`. Production и существующая база preview не используются.

## Среда

Реально установлены WordPress 7.1.4, WooCommerce 11.2.2, PHP 8.4.27 и MariaDB 11.8.6. Дистрибутивы — с официальных серверов; адреса и контрольные суммы записаны в исключённый из Git `data/woocommerce/runtime.json`. SHA256 PHP сверяется с опубликованным значением. Для остальных архивов зафиксирована сумма скачанного через HTTPS файла; это не независимая проверка подписи издателя.

Это установленный магазин, не подмена HTTP-ответов и не проверка внешнего магазина владельца. Каталог, остатки, себестоимость и заказы — явно учебные данные. Локальный HTTPS-прокси только завершает TLS и передаёт запросы настоящему WordPress. Сертификат добавлен исключительно в отдельное хранилище тестового JVM; Windows и production ему не доверяют.

Запуск из `backend`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/woocommerce/start-local.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/woocommerce/start-aria.ps1
```

Требуются локальные PostgreSQL на 55434 (существующий preview), Java 21, Python, Node и OpenSSL из Git for Windows. Внешние пакеты загружаются только при первом запуске. Нет Windows-служб, глобального изменения PATH, платных ресурсов или данных production.

- ARIA: http://127.0.0.1:8085/control.html#stores
- Настоящий учебный магазин: https://127.0.0.1:8449
- Входы: `data/woocommerce/aria-access.txt` и `data/woocommerce/access.txt`.

Эти адреса доступны на этом компьютере. Предупреждение браузера о локальном сертификате относится только к учебному WooCommerce. Файлы конфигурации, ключей, базы, журналов и бинарных пакетов находятся в игнорируемом каталоге с доступом владельца Windows.

## Подтверждение цены

«Мои магазины» → открыть магазин → «Цены и ARIA». Сначала владелец подтверждает себестоимость, минимум, валюту и категорию. Затем отдельно разрешает запись и указывает максимум скидки и интервал. Ввод новой цены требует явного подтверждения.

Сервер перед отправкой проверяет свежесть каталога, известный положительный остаток, неизменившуюся валюту, минимум, себестоимость, подтверждённую базовую цену, интервал и актуальные разрешения. Нельзя накопить скидки сверх установленного предела. Через официальный API отправляется только `regular_price` одного выбранного товара/вариации. Существующая или запланированная акция блокирует операцию. Склад, заказы и другие поля не отправляются.

Успех фиксируется только после отдельного чтения фактической цены и валюты из WooCommerce. Журнал хранит старую/новую цену, источник, подтверждение и результат. Один идентификатор запроса не создаёт повторной операции. При потере ответа сохраняется неопределённое состояние: новая запись блокируется, доступна сверка без повторного PUT. Смена ключей, отключение и архивирование отзывают разрешения записи.

Официальный WooCommerce API не предоставляет атомарного сравнения и изменения цены совместно со всеми сторонними редакторами. Здесь применяется проверка перед записью и чтение после неё, а не распределённая блокировка. Не запускайте параллельные ценовые роботы без отдельного согласованного механизма владения ценой. Автоматического возврата внешней цены при сбое нет: он мог бы перезаписать последующую правку продавца.

## Повторяемые проверки

`scripts/woocommerce/e2e.cjs` использует браузер и установленный магазин: мастер, реальный REST, вариации, валюту, заказы, повторный импорт, разрешённую запись, настоящую доставку WooCommerce и восстановление чтения. Один намеренно потерянный ответ — явная проверка транспортного сбоя; ответ модели или магазина не подделывается. `docs/connected-commerce/evidence/woocommerce-e2e.json` содержит фактический результат последнего запуска. `passed:true` требуется для завершённого прогона.

Контрактные/Java-проверки отдельно: `StorePriceIntegrationTest`, `WooCommerceReaderTest`, существующие тесты импорта и архива. Их нельзя называть внешним E2E.

Для настоящего магазина владельца нужны его HTTPS-домен, разрешение домена оператором ARIA, отдельные WooCommerce REST-ключи и публичный HTTPS-адрес ARIA для уведомлений. Ключ чтения подходит для импорта; изменение цен требует прав Read/Write и отдельного согласия в ARIA. Передавать ключи в чат или Git не нужно.

Официальные контракты: [WooCommerce REST API](https://woocommerce.github.io/woocommerce-rest-api-docs/), [создание ключей](https://woocommerce.com/document/woocommerce-rest-api/), [WordPress](https://wordpress.org/download/), [PHP для Windows](https://windows.php.net/download/), [MariaDB](https://mariadb.org/download/).
